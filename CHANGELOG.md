# Changelog

## 1.0.2

- Make the shared window and detached conversations substantially smaller.
- Use a narrower contact list, eight visible contacts and tighter spacing.
- Keep text readable and scroll the contact list when needed.

## 1.0.1

- Open the messenger from the normal Reply and Reply-to-last-recipient bindings.
- Move normal /w composition into the messenger when its recipient is known.
- Preserve both drafts when the standard chat and messenger already contain different unsent text.

## 1.0.0

- Add a shared contact list for incoming and outgoing whispers.
- Detach conversations by dragging names out, with a separate input in each window.
- Preserve drafts when switching, detaching and reattaching conversations.
- Show unread counts without taking keyboard focus from the game.
- Include the in-game Rebuffed version protocol.
